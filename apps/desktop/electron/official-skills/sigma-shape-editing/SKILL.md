# 図形・矢印・注記を編集する

個別に移動・編集する必要がある要素は、編集可能な図形として配置する。複雑な挿絵や説明図全体は、特に個別編集の指定がなければSVGを優先する。

- 図形の追加は `insert_shape`、既存図形の変更は `update_shape` を使う。
- 配置を整えるときは `align_shapes` を使う。
- SVG画像の内容を修正する場合は `update_svg_image` を使い、新しい図が必要なら `insert_svg_image` を使う。
- 文字注記や数式ラベルが元の図を隠さないようにし、アンカーと重なりを確認する。

既存の図形のIDや配置を維持し、依頼されていない図形を削除しない。変更後は紙面上の位置、回転、サイズ、重なり、ラベルの読みやすさを確認する。
