# 表・増減表を挿入・更新する

表は列と行の対応が明確になるように作成し、空白文字で列をそろえた疑似表を使わない。

- 新しい表には `insert_table` を使う。
- 既存の表やセルを修正する場合は `update_table` を使う。
- 数学の増減表では、区間、臨界点、符号、増減、極値の対応関係を崩さない。
- 単位、桁、負号、空欄の意味を確認し、値を推測で補わない。

変更後は見出しとデータ列の対応、セル内の数式、紙面幅、改ページ位置を確認する。既存の表の構造は、依頼に必要な範囲だけ変更する。
