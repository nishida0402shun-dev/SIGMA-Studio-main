# 問題・解答・解説を作成・更新する

問題は本文に似せた段落の寄せ集めではなく、SigmaDoc の問題ブロックとして扱う。

- 新しい問題の構造を作るときは `create_problem_content` を使う。
- 既存の問題の導入・問題文・解答・解説を直すときは `update_problem_content` を使う。
- 問題の前後に本文を追加する場合だけ `insert_body_content` を使う。
- 問題番号や小問の順番を保ち、指定されていない問題の内容を変更しない。

回答を追加する前に、元の問いに対応しているか、計算と単位が正しいか、導入文と問題文の重複がないかを確認する。解答やヒントが不要と指定された問題には追加しない。
