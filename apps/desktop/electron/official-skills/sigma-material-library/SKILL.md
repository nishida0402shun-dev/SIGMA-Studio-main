# 素材・過去教材を再利用する

ゼロから作る前に、保存済みの素材や過去の教材を探す。見つかったものは、中身と用途を確認してから使い、元の意味や出典を保つ。

## 保存済み素材

1. `list_materials` で部品の一般名・用途を検索する。必要なら検索語を変えて複数回探す。
2. 候補は `get_material` で内容を読み、依頼に合うものだけを `insert_material` で挿入する。
3. 挿入後に位置、大きさ、重なり、周囲のラベルを確認する。接続点がある素材は、他の部品と接続・整列するために利用する。
4. 適切な素材がない場合は、図・イラストには `insert_svg_image`、グラフには `insert_graph`、表には `insert_table` を使う。

## 過去の教材

- `search_library` で既存教材の本文や構成を検索する。語を変えて複数回検索し、似た内容を見つける。
- ユーザーが `@` で指定した教材は `get_mentioned_sigma_docs` で確認する。
- ヒットした文書は `get_document_outline` や `get_blocks` で内容を確認してから参照する。検索結果の抜粋だけで判断しない。
- 過去教材は言い回し・構成・難易度を合わせるために使う。ユーザーが明示しない限り、他教材の問題文や解説をそのまま複製しない。
- 参考にした文書がある場合は、書き込みの参照情報に文書と該当ブロックを記録し、最後の報告で再利用した部分と新規作成した部分を分けて伝える。

## 判断ルール

- 保存済み素材をそのまま使える場合は、似たものをゼロから作り直さない。
- 素材の意味や構造が依頼に合わない場合は、名前が似ているだけで再利用しない。
- 検索結果にない内容は推測で補わない。出典の内容と新しく作成した説明を区別する。
- 挿入後は `render_page` で紙面を確認し、位置・大きさ・重なり・ページのはみ出しを検証する。
