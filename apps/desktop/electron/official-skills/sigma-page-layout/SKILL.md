# ページ設定・段組み・改ページを整える

紙面の形を変えるときは、空段落や空白文字で位置を調整せず、ページ設定や段組みの構造を変更する。

- 用紙サイズ・向き・余白は `update_page_layout` を使う。
- 本文の一部分だけ段組みを変える場合は `update_column_layout` を使う。
- 内容の順序を変える場合は `move_blocks` を使い、本文を削除して作り直さない。
- 改ページが必要なら専用のページ区切り操作を優先し、空の段落を積み上げない。

変更後はページ数、段組みの境界、数式や図のはみ出し、ページ末尾の孤立した見出しを確認する。用紙設定と本文の内容は別々に扱い、要求されていない本文の書き換えは行わない。
